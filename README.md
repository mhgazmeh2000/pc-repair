# 🛠 PC Repair Toolbox Pro + AI Agent

جعبه‌ابزار عیب‌یابی و تعمیر ویندوز با دستیار هوش مصنوعی — رابط کاربری فارسی و راست‌چین.

---

## ✨ قابلیت‌ها

| بخش | توضیح |
|---|---|
| 🧰 **۴۸ ابزار ویندوز** | در ۹ دسته، هر کدام با راهنمای گام‌به‌گام و هشدار ایمنی |
| 🤖 **دستیار هوشمند** | ۵ نقش تخصصی · حافظه گفتگو · اجرای مستقیم دستورات از چت |
| ⚡ **اجرای زنجیره‌ای** | چند دستور پشت‌سرهم با یک بار UAC · خروجی زنده · قابل لغو |
| 🎮 **مرکز کارت گرافیک** | تشخیص Intel/NVIDIA/AMD · خطاهای TDR · نرم‌افزارهای مصرف‌کننده GPU |
| 🔒 **دروازه امنیتی** | سه سطح: مجاز · نیازمند تأیید · مسدود |
| 🗄 **پایگاه داده** | ذخیره دائمی چت‌ها و دستورات در SQLite با جست‌وجو |
| 🌐 **پروکسی سیستم** | استفاده خودکار از پروکسی ویندوز (سایفون، Hiddify و...) |
| 🆓 **تشخیص مدل رایگان** | بر اساس قیمت واقعی API |

## 🚀 اجرا

```cmd
pip install -r requirements.txt
python pc_toolbox_pro.py
```

### ساخت فایل اجرایی

روی **`build.ps1`** راست‌کلیک ← Run with PowerShell
یا:
```cmd

```

خروجی: `dist\PC_Repair_Toolbox_Pro.exe`

📖 راهنمای کامل و عیب‌یابی: [`راهنمای_ساخت_EXE.md`](راهنمای_ساخت_EXE.md)

## ⚙️ تنظیمات اولیه

۱. تب **تنظیمات** را باز کنید
۲. سرویس‌دهنده را انتخاب کنید — پیشنهاد: **Groq** (رایگان، بدون نیاز به پروکسی)
۳. کلید API را از [console.groq.com/keys](https://console.groq.com/keys) بگیرید
۴. **🔍 دریافت فهرست واقعی مدل‌ها** را بزنید
   اگر `verified` سبز شد، کلید شما کار می‌کند
۵. **🧪 تست اتصال** — وضعیت شبکه و اعتبار کلید جدا نمایش داده می‌شود

### سرویس‌دهنده‌ها

۱۴ سرویس داخلی، از جمله سه واسط ایرانی (آوالای، گپ‌جی‌پی‌تی، لیارا) و دو گزینه محلی (Ollama، LM Studio).
می‌توانید سرویس دلخواه خود را هم اضافه کنید — کافی است سازگار با OpenAI API باشد.

## 🔒 امنیت

دستوراتی که AI پیشنهاد می‌دهد مستقیماً اجرا نمی‌شوند. هر دستور از سه لایه عبور می‌کند:

| سطح | رفتار |
|---|---|
| 🟢 **مجاز** | در فهرست سفید — با یک کلیک |
| 🟡 **ناشناخته** | نیازمند تأیید صریح شما |
| 🔴 **خطرناک** | مسدود — حتی با تأیید هم اجرا نمی‌شود |

دستورات بازگشت‌ناپذیر (`format`، `vssadmin delete shadows` و مانند آن) در هیچ حالتی اجرا نمی‌شوند.
